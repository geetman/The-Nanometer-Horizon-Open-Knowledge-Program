# University Browsing
## What is this?
Many universities host course materials — lecture notes, slides, problem sets, and readings — on publicly accessible web pages, with no login or paywall required. Unlike formal open courseware programs (MIT OCW, NPTEL, etc.), these are often just professor personal pages or department directories that happen to be publicly indexed. The content is the same material given to enrolled students, just sitting openly on a university server.

## How to do it?
The core trick is **reverse-engineering URLs**. When you find a useful PDF from a university, strip back the URL path to find the course directory.

**Example:**
```
https://web.engr.oregonstate.edu/~mjb/cs557/Handouts/glman.pdf
↓ remove the filename
https://web.engr.oregonstate.edu/~mjb/cs557/Handouts/
↓ remove the subfolder
https://web.engr.oregonstate.edu/~mjb/cs557/
```
You've now landed on the full course page with all materials.

**Finding PDFs to start from:**
- Google: `site:*.edu filetype:pdf "your subject"`
- Google: `site:university.edu filetype:pdf "lecture notes"`
- Google: `site:university.edu/~professorname` to find all their courses

**Common URL patterns to look for:**
- `web.university.edu/~username/coursecode/` — professor personal pages
- `cs.university.edu/courses/cs101/` — department course directories  
- `people.university.edu/~username/` — faculty pages often have multiple courses

**Note:** This works best with older professor personal pages. Many modern university systems lock directories or require login, so results will vary.

**Using a university's course catalog to browse systematically:**

Some universities publish their full course catalog publicly. You can use this to identify courses by subject, find the course code, then search for open materials using that code.

[Oregon State Course Catalog](https://classes.oregonstate.edu) is a good example of this workflow:
1. Browse the catalog by subject to find a course that interests you
2. Note the course code (e.g. `CS 557`)
3. Search Google: `site:oregonstate.edu "CS 557" lecture notes` or browse `web.engr.oregonstate.edu` for that code
4. Reverse-engineer the URL from any PDF you find

Many universities publish similar public catalogs — look for a `classes.` or `catalog.` subdomain on the university's main domain.
